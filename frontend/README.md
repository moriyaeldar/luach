# Luach frontend

Angular 22 app (standalone components, Signals, zoneless) with Angular Material. Hebrew and English at runtime, RTL and LTR.

```bash
npm install
npm start          # http://localhost:4200, proxies /api to the gateway on :8080
npx ng test --watch=false
npx ng build
```

See the [main README](../README.md) for the full system.
